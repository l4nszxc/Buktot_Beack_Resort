> **Tech Stack:** Semantic HTML5, Vanilla CSS3, Bootstrap 5.3, Client-side LocalStorage DB (No SQL, GitHub Pages Ready).

---

## 🌟 Overview & Concept
Buktot Beach is an eco-tourism destination known as one of Oriental Mindoro's pristine hidden gems. Famous for its powdery white sand, serene calm waters, and violet-tinted geological rock formations, this website presents Buktot Beach Resort as an authentic, sustainable coastal getaway.

All information—including package pricing (**₱150/pax**), services, native cabana rentals, phone hotline (**0926-287-7433**), and the 1-day itinerary schedule—is faithfully integrated directly from the official resort brochure.

## 💻 Tourism Business Tools & Technologies Applied
1. **Online Booking Engine (No SQL):** Uses browser `localStorage` to persist customer reservations across page refreshes.
2. **Local Database Manager Table:** Live admin-style table enabling instructors to view, delete, and export records as JSON.
3. **Interactive Trip Cost Estimator:** Real-time calculator determining tour and cabana costs based on party size.
4. **Interactive Guest Reviews System:** Guests can submit star ratings and testimonials stored immediately in the local database.
5. **Interactive Embedded Map:** Responsive Google Map coordinates pointing directly to Buktot Beach, Manaul, Mansalay.
6. **Brochure Verification Showcase:** Side-by-side verification panels showing official brochure panels and images.
7. **Photo Lightbox Modal:** Fullscreen inspection of authentic photography.

## 🚀 How to Host on GitHub Pages
1. Push this folder to a GitHub repository (e.g. `buktot-beach-resort`).
2. Go to **Settings** > **Pages** in your repository.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
4. Your website will be live in minutes at `https://<your-username>.github.io/<repo-name>/`.
